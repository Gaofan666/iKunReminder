# 自定义宠物形象（皮肤）

不喜欢那只小鸡？自己画一个换掉就行，不用改代码、不用重新打包。

## 〇、自带的几个形象

主界面「🎨 宠物形象」下拉框里直接就能选：

| 文件夹 | 名字 |
| --- | --- |
| （默认） | 默认（代码手绘的小鸡） |
| `dragon/` | 小黄龙 |
| `dog/` | 海盗狗 |
| `panda/` | 熊猫人 |
| `sponge/` | 方块海绵 |
| `star/` | 粉海星 |

这几个都是 `build/make-skins.js` 用 Canvas 现画的（没引用任何外部素材），
想加自己的形象照着它们的格式做就行。

## 一、放哪里

放在**软件安装目录**（`iKunReminder.exe` 所在的那个文件夹）里的 `skins\` 文件夹里，
每个皮肤一个子文件夹：

```
iKunReminder.exe
skins/                        ← 装好之后就有这个文件夹（用户皮肤放这里）
  ├─ 我的猫/                       ← 你自己的，名字随便起（就是显示在列表里的 id）
  │   ├─ skin.json
  │   └─ sheet.png
  └─ （想改哪个自带形象，也可以照它的格式做一份放进来）
resources/skins/              ← 自带形象（随版本更新，不用管）
  ├─ dragon/  ├─ dog/  ├─ panda/  ...
```

**这个 `skins` 文件夹不会被软件更新删掉**：安装程序在更新前会先把它整个备份，装完再放回来；
万一哪次没搬好，程序下次启动还会自动从本机备份里补回来。
找不到文件夹时，可以在**设置 → 「🎨 打开皮肤文件夹」**直接打开它。

放好之后**重启软件**，主界面「🎨 宠物形象」下拉框里就会出现它。

> 程序的查找顺序：`exe 同级的 skins/`（你放的）→ `安装目录\resources\skins\`（自带的）
> → 开发时的项目根目录 `skins/`。同一个 id 只认第一个找到的，
> 所以你想改自带的某个形象，把自己的版本用同名文件夹放在 `skins\` 里就行。

## 二、skin.json 怎么写

```json
{
  "name": "示例：跳跳球",
  "author": "自带模板",
  "frame": { "w": 180, "h": 211 },
  "fps": 10,
  "sheet": "sheet.png",
  "animations": {
    "idle":  { "row": 0, "count": 4 },
    "dance": { "row": 1, "count": 6 },
    "cheer": { "row": 2, "count": 6 }
  }
}
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `name` | 否 | 下拉框里显示的名字，缺省用文件夹名 |
| `author` | 否 | 作者，会显示成「名字 — 作者」 |
| `frame.w` / `frame.h` | **是** | **单帧**宽高（像素），不是整张图的尺寸 |
| `fps` | 否 | 每秒播几帧，默认 10 |
| `sheet` | 否 | 精灵图文件名，默认 `sheet.png` |
| `animations` | **是** | 三种状态各自用哪一行、有几帧 |

每种状态还能单独指定帧率（`fps`），不写就用上面那个全局的：

```json
"animations": {
  "idle":  { "row": 0, "count": 4, "fps": 4 },
  "dance": { "row": 1, "count": 6, "fps": 12 },
  "cheer": { "row": 2, "count": 6, "fps": 10 }
}
```

> 待机建议放慢（3～5 fps）：帧数少、帧率高的话会一直在抖，看久了很烦。

### 三种状态

程序会在不同时机切状态，所以三个都要给（至少要给 `idle`）：

| 状态 | 什么时候用 |
| --- | --- |
| `idle` | 平时待机，一直在播 |
| `dance` | 到点弹提醒、全屏庆祝时 |
| `cheer` | 你点了「我喝了 / 我休息了」之后 |

### 精灵图怎么排

一张 PNG，**每行一种状态，左到右是帧序列，格子和帧一样大**：

```
      第0列    第1列    第2列    第3列    第4列    第5列
row0  idle0   idle1   idle2   idle3   （空）   （空）
row1  dance0  dance1  dance2  dance3  dance4  dance5
row2  cheer0  cheer1  cheer2  cheer3  cheer4  cheer5
```

所以上面那份示例的图是 **6 列 × 3 行 = 180×6 × 211×3 = 1080 × 633**。

用不到的格子留空就行。背景**透明**（PNG 带 alpha），否则会看到一个方块。

### 尺寸和对齐

- 角色在画面里**横向居中、脚底贴地**，程序按这个来摆你的图。所以画的时候让角色站在格子底部中间就行。
- 程序会自动把你的帧缩放到和自带小鸡差不多高，**不用刻意去凑尺寸**。
- 但**同一张图里所有帧的尺寸必须一致**，而且角色在各帧里的位置要稳定，否则会抖。

## 三、最快的上手方式

1. 把 `skins/dragon/` 整个复制一份，改个文件夹名
2. 打开 `sheet.png`，把你自己的角色画进那些格子里（保持 6×3 的格子划分）
3. 用记事本改 `skin.json` 里的 `name` / `author`
4. 重启软件，在下拉框里选它

## 四、出问题怎么办

- **下拉框里没有你的皮肤**：检查 `skin.json` 是不是合法 JSON（多一个逗号就会失败），
  以及 `frame` / `animations` 有没有缺。格式不对的皮肤会被静默跳过，不会影响软件启动。
- **显示成一块白/黑方块**：精灵图没抠透明。
- **动画错位、串帧**：`frame.w/h` 和实际格子尺寸对不上，或者 `count` 写多了。
- **根本没换**：下拉框选了之后要等一下（图片是异步加载的）。

## 五、自己生成一张精灵图

不想手画的话，用代码画也行 —— 见 `build/make-demo-skin.js`，
它就是用 Canvas 逐帧画完再拼成精灵图的，改改里面的绘制函数就能生成你自己的。
