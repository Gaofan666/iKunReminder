# 电子提醒器 · 喝水休息提醒 🐣🏀💧

一个 Windows 桌面小软件（也是「电子宠物」）：

- **常驻右下角系统托盘**：点 ✕ 只是收进托盘，不退出；到点会**自己弹回最前台**提醒你。
- 桌面上是只**黄色小鸡**，画得比较抽象：脑袋又大又歪、银灰中分乱发一撮一撮、
  眼睛一大一小还各瞟各的、鸭嘴是歪的、红脸蛋一边大一边小；身上是黑卫衣（拉链 + 浅色背带）、
  浅灰背带裤、黑鞋，篮球抱在画面左手边。平时轻轻摇摆运球，到点火力全开唱跳 rap 篮球，
  打卡完成会举手欢呼。
- **宠物模式**：缩成右下角一个**背景全透明**的小窗，屏幕上只剩小鸡在动，
  **任务栏图标自动隐藏**，只在托盘留一个图标；按住左键整窗都能拖，**右键**出菜单。
- 提醒会同时给：全屏动画 + 原创 8-bit 旋律 + 中文语音播报 + 系统通知 + 任务栏闪烁。
- **主界面随窗口等比缩放**，窗口拉大拉小都是整比例缩放，不会挤成一团或留一大片白。

> **平时完全不联网**：待办、备忘、设置、统计全部只存在本机，不上传任何东西。
> 唯一会联网的地方是设置页的「检查更新」——只在你点它、或者你开着自动检查时，
> 去向 GitHub 问一句「有没有新版本」。
> 除 Electron 运行时外只有一个第三方依赖 `electron-updater`，就是为了这个自动更新。
> 角色、篮球、霓虹舞台全部是 Canvas 代码实时绘制的**原创美术**，音效是 Web Audio 实时合成。

## 🆕 v4.3.0 更新（桌宠置顶开关 + 逾期/延期分开统计 + 待办/备忘分类）

### 🐣 桌宠被压住了？现在有个开关

1. **新增「📌 桌宠始终最前」开关（默认关闭）**：桌宠原来用的是最低一档的置顶，而 Windows 上**所有置顶窗口共用同一层，谁最后被激活谁就在最上面** —— 被别的置顶软件（或者软件自己的提醒窗）压住之后，它就再也回不来了。勾上这个开关之后，桌宠会自己盯着层级，**一旦被压住就重新提到最前**：只改层级，**不抢焦点、不打断你打字**。
   **默认不开，原来的规则一点都不变**；设置页「桌面宠物」里能勾，托盘菜单和桌宠右键菜单里也有同一项。睡眠唤醒、提醒窗关掉之后都会自动重新提一次；**全屏提醒正在显示的时候它会主动让位**，不挡提醒。

### 📝 逾期和延期是两件事，分开记

2. **先说清楚两个词**（待办、备忘一视同仁）：

   | 计数 | 什么时候 +1 |
   | --- | --- |
   | **逾期** | **一个截止时间被错过** —— 到点了还没完成，就一定算一次 |
   | **延期** | **你把截止时间往后挪了一次** |

   两件事互相独立，所以「错过旧期限之后又改期」就是**逾期 1 次 + 延期 1 次**；改期之后又没赶上新期限，就是**逾期 2 次 + 延期 1 次**。

   - **截止前完成** → 两个都是 0。
   - **在截止前就把时间往后挪**（主动顺延），新期限前完成 → **不算逾期**，只记 1 次延期。
   - **改早、清空截止时间** → **不算延期**（只有往后挪才算）。
   - **重复待办勾完自动排下一期** → **不算延期**，那一期没完成才算逾期。
   - **逾期由程序自己判定，不看你点没点提醒**：到点那一刻还没完成就记一笔，提醒弹窗被你晾着、或者被 12 小时宽限静默清掉，都不会漏记。
   - **同一个截止时间最多记一次**：同一个期限里反复点「我知道了 / 10 分钟后再说」，或者「取消完成再勾一次」，都只算 1 次 —— 去重键是截止时间本身，重启也不会重复记。

3. **逾期提醒里可以顺手写一句原因**：5 个快捷原因（时间不够 / 被打断 / 等别人 / 忘了 / 事情变多）+ 可以自己写，**留空也行**。
4. **备忘列表最下面挂了一条逾期统计**（做得低调，不抢列表的位置）：`📊 逾期备忘 N 条 · 累计 X · 平均 Y · 逾期共 N 次 · 延期 N 次 · 原因分布`，**点一下展开明细**（每条拖了多久、当时写的原因）。
5. **卡片上挂「逾期 N 次」和「延期 M 次」两个小标**（颜色不同，一眼分得开），鼠标停上去能看到拖了多久 / 什么原因 / 最近一次挪到了哪天。
6. **逾期过、又一直没写原因的，完成的时候会让你补一句**：勾完成时会先弹「这条备忘逾期了 —— 补一句？（不写也行）」，可以点快捷原因、自己写，或者**点「跳过，直接完成」**。跳过的也没关系 —— 卡片上会留一个「**补原因**」按钮，什么时候想补都行（已经完成的备忘补原因不会改变它的完成状态）。这个按钮**只认真的逾期过的备忘**（确实错过了截止时间才算）—— 截止时间早已过去、但当时并没拖的备忘不会被追着补原因，也不会被标成逾期。
**老数据只补有据可查的**：只有「确实完成得比截止晚」（存着完成时间、且真晚于截止）的备忘才会被补记一笔逾期，时长按「截止 → 完成时间」算。没有完成时间的老数据**不会被翻旧账** —— 包括**写过逾期原因的也不算数**：那可能只是当时被弹窗问出来的，并不代表真拖过（早期版本只要有截止时间过去就会追问原因，所以「有原因」不能当证据）。

### 🗂 做完的自动收起来，列表只留没做完的

7. **已完成的收进一条折叠栏**（待办、备忘都有）：列表默认**只留未完成的**，最下面多一条象小标题的 `🗂 已完成 N 条 展开 ▼`（图标 + 加粗 + 独立底色 + 右侧箭头，不是那种一划而过的小灰字），**点一下才展开**。展开**先摆最近完成的 5 条**，多出来的再有一个 `更早的 N 条 ▾` 二级开关放出来。
   **不按「最近一周」分组** —— 早期版本没存完成时间，老数据全都算不出「一周内」，那样点开会一条都看不到；现在按完成时间（没有完成时间的就按记录时间）从新到旧取前 5 条，**点开一定有东西看**。**折叠状态不跨重启记住**（和分类筛选一样，每次打开都是干净的收起状态）。

### 🏷 待办和备忘可以分类了

8. **自定义分类，待办和备忘共用一套**：入口在 **设置页左侧导航的「🏷 分类」**（也可以把设置页拉到最下面找它），可以**新建 / 改名 / 换色（直接调色盘）/ 删除**，每一项还显示有多少条内容在用它。**删除分类不会删内容** —— 那些内容会自动回到「未分类」。
9. **新增 / 编辑弹窗里可以选分类**；列表上方多出一条**彩色分类筛选条**（全部 / 各个分类 / 未分类），点一下只看这一类；卡片上显示彩色分类小标（待办、备忘都有）。

### 🛠 其他

10. **新增 5 个自检开关**：`--diag-pettop`（桌宠置顶）、`--diag-late`（逾期统计）、`--diag-cat`（分类）、`--diag-why`（补填逾期原因）、`--diag-count`（逾期 / 延期两个计数器的口径），都是照真实界面点一遍的端到端自检。

## 🐛 v3.2.3 修复（一键摸鱼会把动态壁纸收掉）

v3.2.2 的「一键摸鱼」是「把所有有标题的可见窗口都最小化」，结果**把 Wallpaper Engine
这类动态壁纸软件也收走了** —— 壁纸是画在挂在 `WorkerW` / `Progman`（桌面壳层）下面的
窗口里的，一旦被最小化，桌面就只剩纯色背景，而且它自己不一定恢复得回来。

现在加了**两道白名单判断**，这几类窗口一律不碰：

| 维度 | 不碰的东西 |
| --- | --- |
| **窗口类名** | `Progman` / `WorkerW`（桌面本体）、`Shell_TrayWnd`（任务栏）、`SysListView32`（桌面图标）、`Windows.UI.Core.CoreWindow`、以及一批 XAML 壳层窗口 |
| **进程名** | Wallpaper Engine（`wallpaper32/64`、`ui32/64`）、Lively（`lively`、`livelywpf`）、Rainmeter、DeskScapes、DreamScene、`dynamicwallpaper` 等 |

> **还能自己补**：如果用的是别的动态壁纸软件没被认出来，在
> `%APPDATA%\iKunReminder\moyu-skip.txt` 里写它的进程名（一行一个，或用逗号分隔）就行，
> 摸鱼时会一并跳过。

> 💡 **壁纸还是没回来？** 这多半是 Wallpaper Engine 自己的「其他程序最大化时暂停」
> 在起作用 —— 摸鱼会打开一个最大化的文档，它会据此暂停壁纸。在 Wallpaper Engine
> 设置里把那条暂停规则关掉，或者退出重开一次 Wallpaper Engine 即可。

## 🆕 v3.1 更新（多屏 / 高 DPI 适配）

之前的版本只按「窗口的 CSS 像素」排版，**完全没看显示器的缩放设置**，于是界面在屏幕上的
物理大小只由分辨率决定 —— 分辨率越高字越小：

| 屏幕 | 系统缩放 | 改动前界面占屏宽 | 看起来 |
| --- | --- | --- | --- |
| 1K 1920×1080 | 100% | 61% | 偏大 |
| 2K 2560×1440 | 100% | 46% | 基准，正常 |
| 4K 3840×2160 | 150% | 31% | 偏小 |
| 4K 3840×2160 | 100% | 20% | 很小 |

而且没有任何窗口跨屏 / DPI 变化的监听：从 2K 屏把窗口拖到 4K 屏，界面不会重新适配。

现在改成**按物理尺寸恒定**：

- 因子 `k = 当前屏像素比 ÷ 基准屏像素比`（基准屏 = 第一次运行软件时所在的主显示器）。
- 窗口逻辑尺寸 = 物理设计尺寸 ÷ k，页面内容缩放 = k —— 两条合起来，
  **界面和字在任何分辨率、任何缩放档下在屏幕上都一样大**。
- 跨屏拖动会在拖动停下后按新屏重新适配（拖动过程中不动窗口，不打断你拖）。
- 宠物窗和说话气泡是「按物理尺寸摆放的独立小窗」，也一起换算，换屏后大小不变。
- 基准屏上 k = 1，**界面与改动前完全一致**，没有任何行为变化。

> 实测（本机 150% 屏上模拟 100%/125%/150%/200% 四档系统缩放）：
> 内容块出屏物理尺寸稳定在 1770×1293 物理像素、14px 正文字号稳定在 28 物理像素，
> 四档完全一致；宠物窗物理尺寸稳定在 150×170。
>
> 顺带修掉的老问题：① 设计高常量写的是 842，而内容真实布局高 862，
> 连基准屏上都被压扁 2.4%；② 进入宠物模式时没放开窗口最小尺寸，
> 宠物窗会被 Windows 夹成 760×560；③ 窗口 resize 时本地的 devicePixelRatio
> 会覆盖主进程给的权威缩放值，跨屏瞬间算出错误的缩放。

### 相关文件（v3.1 ～ v3.2.2）

| 文件 | 作用 |
| --- | --- |
| `ui-scale.js` | 缩放因子算法（纯函数，主进程/页面/Node 单测共用） |
| `pet-draw.js` | 角色绘制 + 皮肤精灵图 + 8-bit 音效 —— 主界面舞台与桌面宠物窗**共用同一份** |
| `skin-picker.js` | 皮肤「取列表 / 载入」的薄封装（要调主进程桥，所以单独放） |
| `pet.html` / `pet.js` / `pet-preload.js` | 桌面宠物独立小窗（透明、置顶、可拖、右键菜单） |
| `build/patch-icon.js` | 打包后给 exe 换图标 + 写版本信息（绕开 winCodeSign 的符号链接问题） |
| `build/write-app-update.js` | 生成 `resources/app-update.yml`（更新器靠它找更新源）。**必须自己写**：我们的两步构建里 electron-builder 的 `afterPack` 不会执行，它自己不生成 |

打包形式有三种，**启动速度差很多**，按需要挑（都是同一台机器上实测的）：

| 形式 | 产物 | 首次启动 | 之后每次启动 | 适合 |
| --- | --- | --- | --- | --- |
| 🏆 **安装版** | `dist\iKunReminder-setup-v<版本号>.exe`（100 MB） | 3.2 秒 | **0.87 ～ 1.06 秒** | 日常用、发给别人 |
| 🏆 **绿色解压版** | `dist\win-unpacked\` 或 `dist\iKunReminder-绿色版.zip`（139 MB） | 3.4 秒 | **0.68 ～ 0.75 秒** | 免安装、放 U 盘 |
| 🐢 **单文件便携版** | `iKunReminder.exe`（98 MB） | 10.4 秒 | **10.4 ～ 11.7 秒** | 应急携带，不建议日常用 |

### 推荐一：安装版（单文件，装一次就快）

双击 `dist\iKunReminder-setup-v<版本号>.exe`，会走一个**三步向导**：

1. **安装选项** —— 选「仅为我安装」（默认，不需要管理员权限）还是给所有人装；
2. **选定安装位置** —— 默认 `%LOCALAPPDATA%\Programs\iKunReminder`，
   想换地方就点右边的**「浏览(B)...」**自己挑目录；
3. **快捷方式** —— 开始菜单的快捷方式一定会创建；
   **「在桌面创建快捷方式」是个勾选框，默认勾上，不想要就点掉**（这个页面回车/空格都行）。

装完每次打开都是 **1 秒左右**。卸载走系统「设置 → 应用」，
或者开始菜单里右键图标 → 卸载。

> **安装后的名字**：安装目录、exe、开始菜单/桌面快捷方式、控制面板里的条目
> 都叫 **iKunReminder**。
>
> 静默安装（`iKunReminder-setup-v<版本号>.exe /S`）会跳过向导，按默认值走：装到默认目录、创建桌面图标。
> 想静默装到指定目录可以加 `/D=路径`（NSIS 的规矩：`/D` 必须放在最后且不加引号）。

### 推荐二：绿色解压版（不装、最快）

把 `dist\iKunReminder-绿色版.zip` 解压到任意目录，双击里面的 `iKunReminder.exe`，
**0.7 秒**开界面。完全不写系统、不留痕迹。想放桌面：右键 exe → 发送到 → 桌面快捷方式。

### 便携版为什么慢？不是配置问题

electron-builder 的便携版 NSIS 模板（`portable.nsi`）每次启动都会
`RMDir /r` 清空临时目录 → **把 320 MB 整个解压一遍** → 运行 → 退出时再删掉。
所以 10 秒里绝大部分是解压，跟机器快慢关系不大。想要"单文件又秒开"只能自己写启动器，
不如直接用上面两种。

### 改代码调试：双击 `启动.cmd`

源码方式运行，改完 `app.js` / `style.css` 刷新就能看效果。

> 第一次打开后**随便点一下页面**，系统才允许播放声音和语音。

### 自己重新打包

```
npm install              # 第一次
npm run build            # 安装版  → dist\iKunReminder-setup-v<版本号>.exe
npm run build:fast       # 绿色版  → dist\win-unpacked\
npm run build:portable   # 便携版  → dist\iKunReminder-便携版.exe
```

> **安装版产物命名**：固定为 `iKunReminder-setup-v<版本号>.exe`，版本号取自 `package.json`
> 的 `version` 字段，由 `nsis.artifactName` 里的 `${version}` 宏自动填入 ——
> **改版本只改 `package.json` 一处**，产物名跟着变，不用手动改名。
> 名字**必须是纯 ASCII**：GitHub Release 的附件名不支持中文，会把中文部分静默吃掉
> （`iKunReminder-安装版.exe` 会变成 `iKunReminder-.exe`，接口还返回 200 不报错）。
> 完整的打包 + 上传流程见仓库根目录 `打包上传流程.txt`。
> 绿色版 / 便携版仍是中文名，它们只在本机用、不上传，所以不受这个限制。

> 打包配置里写死了 `"signAndEditExecutable": false`。原因是 electron-builder 默认会下载一个
> 含 macOS 符号链接的 `winCodeSign` 工具包，普通（非管理员）Windows 账户解压时会报
> 「无法创建符号链接」而打包失败。关掉 exe 签名后就不下载它了，
> 而外壳的图标由 NSIS 负责，**角色图标照常显示**（实测导出来确认过）。
> 另外 `electronLanguages` 只保留了 `zh-CN` / `en-US`，能省掉几十种用不到的语言包。
>
> 「桌面快捷方式」那个勾选框是自己写的，在 `build/installer.nsh` 里，
> 通过 electron-builder 的三个钩子接进去：
> `customInit`（默认值）、`customPageAfterChangeDir`（插在选目录页之后的页面）、
> `customInstall`（electron-builder 建完快捷方式后，按勾选状态决定删不删）。
> 两个坑记一下：① 这个文件是在 MUI2 **之前**被 include 的，用到 `MUI_HEADER_TEXT` 的函数
> 必须写在 `customPageAfterChangeDir` 宏里；② 打卸载程序时也会 include 本文件，
> 整段要用 `!ifndef BUILD_UNINSTALLER` 挡掉，否则变量未使用会触发 warning 6001（被当作错误）。
> 文件必须存成**带 BOM 的 UTF-8**，否则 NSIS 会把中文按 ANSI 解析成乱码。
>
> **快捷方式图标**：快捷方式的图标取自目标 exe，而被安装的 `iKunReminder.exe` 自己**没有图标资源**
> —— 那要靠 rcedit 写进去，但 rcedit 是由 app-builder 的 Go 二进制执行的、需要解压 `winCodeSign`，
> 那个包里带 macOS 符号链接，普通 Windows 账户解压会报「无法创建符号链接」直接失败
> （`signAndEditExecutable: false` 就是为了绕开它）。
> 所以改成：`build/make-ico.js` 把 `icon.png` 转成 `build/icon.ico`
> （手写的 ICO 头 + PNG 内嵌，Vista+ 支持），用 `extraResources` 一起装到 `<安装目录>\resources\icon.ico`，
> 再在 `customInstall` 里让快捷方式直接指向它。实测桌面和开始菜单图标都变成角色头像了。

## 二、托盘

启动后右下角会出现一个**角色头像托盘图标**（和任务栏图标是同一张图），右键它：

| 菜单项 | 作用 |
| --- | --- |
| 显示主界面 | 把窗口叫出来 |
| 宠物模式（只剩动画） | 打勾即缩成只剩动画的透明小窗，悬浮在右下角 |
| 💧 立即提醒喝水 / 🛋️ 立即提醒休息 | 立刻弹提醒（用来测试） |
| ⏸ 暂停计时 / ▶ 继续计时 | 临时免打扰 |
| 退出 | 真正退出程序 |

- **左键单击托盘图标** = 显示 / 收起窗口。
- **点窗口右上角 ✕** = 收进托盘（第一次会弹气泡提示），程序继续在后台计时。
- 到点提醒时窗口会自己从托盘弹出来、置顶、抢焦点；你点「我完成了 / 稍后再说」之后，
  它会**自己缩回托盘**，不打扰你干活。

## 三、宠物模式

点主界面上的「🐣 宠物模式」，或者右键托盘图标勾选，窗口就会变成一个 **150 × 170 的小窗**
并且**窗口背景完全透明**——**没有方框、没有边框、没有按钮、没有倒计时、没有标题栏**，
屏幕上只剩一只小鸡在那儿晃。**任务栏图标也会隐藏**，只在右下角托盘里留一个图标。

**宠物默认大小在主界面上就能设**：主界面左侧舞台下方有「🐣 宠物默认大小」三个档位
（迷你 150×170 / 小小 118×134 / 超小 92×104），选好之后会自动记住并立即生效。

在这个小窗里：

- **按住左键直接拖**：整个窗口都能拖（透明区域也能拖）。
  **窗口会被限制在屏幕可用区域内**，怎么拖都不会跑出屏幕外面去。
- **右键** → 原生菜单：
  - **显示主界面**：恢复完整窗口（任务栏图标也跟着回来）
  - **收进托盘**：藏起来后台继续计时
  - **调整倒计时** → 子菜单：💧 喝水间隔（15/30/45/60/90 分钟）、🛋️ 休息间隔（20/40/60/90/120 分钟）
  - **宠物大小** → 迷你（150×170，默认，最大档）／小小（118×134）／超小（92×104）
  - **退出**

**到点提醒时会自动切回大主界面**（小窗塞不下提醒弹层），完整显示动画和按钮；
你点完「我完成了 / 稍后再说」之后，它会**自动变回小宠物**继续待在角落。

## 六、常见问题

**Q：关了窗口就没了？**
点 ✕ 是收进托盘，还在后台计时。要真正退出：右键托盘图标 → 退出。

**Q：怎么升级到新版本？还要先卸载吗？**
**不用卸载。** 从 v3.2.1 起，设置页有「⬆ 软件更新」：
有新版本时会显示出来，点「下载新版本」→ 下好了点「重启并安装」，
它会自己关掉软件、静默装好、再把新版打开，**待办备忘设置都不丢**。

> 只有 **v3.2.1 本身**要手动装一次 —— 更早的版本里没有更新器，没法自己更新自己。

**Q：自动更新会不会偷偷装？会不会联网上传我的数据？**
都不会。策略是**只提示**：查到新版本只显示出来，**不自动下载、更不自动安装**，
下载和安装都要你亲手点。联网也只有在检查更新那一下，去向 GitHub 问一句有没有新版，
待办、备忘、设置这些从来不上传。

**Q：一键摸鱼按了没反应？**
先看设置页那张卡片上**实际生效的快捷键是哪个** —— 默认的 `Ctrl + Alt + M` 经常被
别的软件占用，这时它会自动换成 Ctrl+Shift+M 之类的，卡片上会写明。
另外它只收「有窗口的程序」，本来就已经最小化的窗口它不动。

**Q：一键摸鱼会不会把我的文档弄丢？**
不会。它只做两件事：把窗口最小化、把伪装目标打开。不关程序、不存盘、不删东西。
再按一次会把**这次收起来的那些**窗口原样还原。

**Q：便携版 exe 第一次打开要等很久？**
便携版**每次**都要等 10 秒左右 —— 它每次启动都会把 320 MB 解压到临时目录，这是
electron-builder 便携版的固有设计（见上面「便携版为什么慢」）。
想要快就换成安装版或绿色解压版，**1 秒以内**。

**Q：便携版会被杀毒软件/SmartScreen 拦？**
可能性有。便携 exe 是从压缩包解出来的，Windows 可能给它打上「来自 Internet」标记。
解决：**先右键 exe → 属性 → 勾选「解除锁定」**，再运行；杀毒软件误报就加个白名单
（Electron 打包的绿色软件比较容易被启发式引擎盯上）。

**Q：宠物模式里怎么没有按钮？**
故意的，只剩小鸡。所有操作都在**右键菜单**里；**按住左键直接拖**就能把它挪到任意位置
（拖不出屏幕范围）；嫌大嫌小可以在右键菜单 →「宠物大小」，或者回主界面用「宠物默认大小」选。

**Q：宠物模式下来提醒了会怎样？**
会自动切回**大主界面**显示完整提醒（小窗塞不下），你点完「我完成了 / 稍后再说」后
它又自动变回小宠物待在角落。

**Q：没声音 / 没语音？**
先和页面交互一次（点一下「🎤 试听提醒」解锁音频）。语音用系统自带的 `speechSynthesis` 中文语音。

**Q：托盘里找不到图标？**
Windows 会把不常用的图标折叠进「隐藏的图标」小三角里，拖出来固定即可。

**Q：想开机自启？**
把 `启动.cmd` 的快捷方式丢进 `Win + R` → `shell:startup` 打开的启动文件夹。

**Q：想改默认间隔 / 角色大小？**
`app.js` 顶部 `settings` 改 `minutes`；角色大小改 `setPetMode()` 和 `new Kunkun(...)` 里的 `fit`（数值越小角色越大）。

## 七、给程序员的备注

- **抢前台**：渲染进程到点调 `window.kunkunNative.alert()` → 主进程
  `restore → show → setAlwaysOnTop('screen-saver') → moveTop → focus → flashFrame`；
  `dismiss()` 后取消置顶，若提醒前藏在托盘里还会自动缩回去。
- **托盘 + 无边框 + 透明**：窗口 `frame:false` + `transparent:true`，普通模式靠页面自身的不透明背景
  铺满窗口，宠物模式把背景全部设为透明，于是屏幕上只剩角色本体。
  `close` 事件里 `preventDefault()` 改为 `hide()`，只有 `before-quit` 才真退出。
- **拖窗**：没用 `-webkit-app-region: drag` ——它在透明窗口上不生效（宠物窗拖不动就是这个原因），
  改成页面里监听 `pointerdown/move/up`，把 `screenX/screenY` 的位移发给主进程 `win.setBounds()`
  自己算偏移，透明区域和普通标题栏都能拖，且不影响右键。
  位置用 `screen.getDisplayNearestPoint()` 取鼠标所在显示器的 `workArea` 做钳制，
  窗口永远不会被拖出屏幕（多显示器、负坐标也都对）。
- **等比缩放**：页面里有个固定 1180px 宽的设计容器 `#app`，窗口尺寸变化时按
  `min(可用宽/1180, 可用高/内容高)` 算比例，用 `transform: scale()` 缩放并居中；
  内容高是运行时量的，避免最后一截被切掉。画布的 `resize()` 改用 `offsetWidth/offsetHeight`
  （不受 transform 影响）拿布局尺寸，再乘上 `devicePixelRatio × 缩放比` 分配像素，缩放后不会发虚。
- **屏幕缩放（DPI）适配**：见 `ui-scale.js`。契约只有两条 ——
  ① 主进程：窗口逻辑尺寸(DIP) = 物理设计尺寸 ÷ k；
  ② 页面：内容 scale = min(可用/设计, 1) × k。
  `k = 本屏像素比 ÷ 基准屏像素比`（基准屏 = 首次启动时的主显示器，之后固定）。
  宽度在所有屏幕上都精确恒定；高度受屏幕可用区限制，屏幕不够高时内容按可用空间等比缩小，
  高度观感因此有 ±5% 左右的浮动 —— 宽高要同时精确恒定在数学上是互斥的
  （标题栏的物理高会随缩放比变化），而宽度与字号观感关系最大，所以优先保它。
  换屏时主进程在 `move` 事件里判断窗口落到了哪块屏，等拖动停下（180ms 防抖）再重排并
  通过 `display-info` 通知页面；`display-metrics-changed` / `display-removed` 兜住插拔与改缩放。
  宠物窗和气泡窗按「真实像素比因子」定尺寸（不吃自检的模拟值），页面里宠物的画布
  `fit = 268 × 真实k × 真实像素比`，两边配合后宠物换屏大小不变。
- **提醒与宠物模式**：`bringToFront()` 里如果当前是宠物模式，先 `applyPetMode(false)` 切回大主界面
  （否则 150×170 的小窗塞不下弹层），并在 `dismiss` 后延迟 1.8 秒自动变回宠物。
  窗口的 `minWidth/minHeight` 要按模式切换（主界面 760×560，宠物模式 80×80），
  否则宠物窗缩不到最小档。
- **任务栏图标**：宠物模式 `setSkipTaskbar(true)`，回主界面 `setSkipTaskbar(false)`。
  注意：Electron 在 Windows 上**不是**靠 `WS_EX_TOOLWINDOW` 实现的，所以用
  `GetWindowLongPtr(GWL_EXSTYLE)` 去验证会得到"没生效"的误判——
  实际要截任务栏截图肉眼比对才准（实测按钮确实会消失）。
- **图标同一张图**：`icon.png`(256) 和 `tray.png`(32) 由同一张画布渲染后再缩放，
  保证任务栏和托盘看到的完全是同一个角色头像。
- **计时**：用 `Date.now()` 时间差推进而非累加，被节流或系统休眠后回到前台按真实时间结算；
  Electron 侧另开 `backgroundThrottling: false`。
- **动画**：`requestAnimationFrame` + Canvas 2D 实时绘制，用了挤压拉伸（腾空拉长 / 落地压扁）、
  呼吸、头发延迟半拍的跟随甩动；篮球被持球手用两段式 IK 真实跟随（运球 / 抱起 / 欢呼三种状态）。
- **音效**：Web Audio `OscillatorNode` 实时合成，没有音频文件。
- **安全**：`contextIsolation: true` + `nodeIntegration: false` + 严格 CSP。
