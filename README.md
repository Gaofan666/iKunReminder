# 电子坤坤 · 喝水休息提醒器 🐣🏀💧

一个 Windows 桌面小软件（也是「电子宠物」）：

- **常驻右下角系统托盘**：点 ✕ 只是收进托盘，不退出；到点会**自己弹回最前台**提醒你。
- 桌面上是只**黄色小鸡坤坤**，画得比较抽象：脑袋又大又歪、银灰中分乱发一撮一撮、
  眼睛一大一小还各瞟各的、鸭嘴是歪的、红脸蛋一边大一边小；身上是黑卫衣（拉链 + 浅色背带）、
  浅灰背带裤、黑鞋，篮球抱在画面左手边。平时轻轻摇摆运球，到点火力全开唱跳 rap 篮球，
  打卡完成会举手欢呼。
- **宠物模式**：缩成右下角一个**背景全透明**的小窗，屏幕上只剩坤坤在动，
  **任务栏图标自动隐藏**，只在托盘留一个图标；按住左键整窗都能拖，**右键**出菜单。
- 提醒会同时给：全屏动画 + 原创 8-bit 旋律 + 中文语音播报 + 系统通知 + 任务栏闪烁。
- **主界面随窗口等比缩放**，窗口拉大拉小都是整比例缩放，不会挤成一团或留一大片白。

> 不联网、无第三方依赖（除 Electron 运行时）。
> 角色、篮球、霓虹舞台全部是 Canvas 代码实时绘制的**原创美术**，音效是 Web Audio 实时合成。

## 一、怎么用

打包形式有三种，**启动速度差很多**，按需要挑（都是同一台机器上实测的）：

| 形式 | 产物 | 首次启动 | 之后每次启动 | 适合 |
| --- | --- | --- | --- | --- |
| 🏆 **安装版** | `dist\iKunReminder-安装版.exe`（100 MB） | 3.2 秒 | **0.87 ～ 1.06 秒** | 日常用、发给别人 |
| 🏆 **绿色解压版** | `dist\win-unpacked\` 或 `dist\iKunReminder-绿色版.zip`（139 MB） | 3.4 秒 | **0.68 ～ 0.75 秒** | 免安装、放 U 盘 |
| 🐢 **单文件便携版** | `iKunReminder.exe`（98 MB） | 10.4 秒 | **10.4 ～ 11.7 秒** | 应急携带，不建议日常用 |

### 推荐一：安装版（单文件，装一次就快）

双击 `dist\iKunReminder-安装版.exe`，会走一个**三步向导**：

1. **安装选项** —— 选「仅为我安装」（默认，不需要管理员权限）还是给所有人装；
2. **选定安装位置** —— 默认 `%LOCALAPPDATA%\Programs\iKunReminder`，
   想换地方就点右边的**「浏览(B)...」**自己挑目录；
3. **快捷方式** —— 开始菜单的快捷方式一定会创建；
   **「在桌面创建快捷方式」是个勾选框，默认勾上，不想要就点掉**（这个页面回车/空格都行）。

装完每次打开都是 **1 秒左右**。卸载走系统「设置 → 应用」，
或者开始菜单里右键图标 → 卸载。

> **软件名 vs 界面名**：安装后目录、exe、开始菜单/桌面快捷方式、控制面板里的条目
> 都叫 **iKunReminder**；但**软件界面里还是「电子坤坤」**（标题栏、托盘提示都没动）。
>
> 静默安装（`安装版.exe /S`）会跳过向导，按默认值走：装到默认目录、创建桌面图标。
> 想静默装到指定目录可以加 `/D=路径`（NSIS 的规矩：`/D` 必须放在最后且不加引号）。

### 推荐二：绿色解压版（不装、最快）

把 `dist\iKunReminder-绿色版.zip` 解压到任意目录，双击里面的 `iKunReminder.exe`，
**0.7 秒**开界面。完全不写系统、不留痕迹。想放桌面：右键 exe → 发送到 → 桌面快捷方式。

### 便携版为什么慢？不是配置问题

electron-builder 的便携版 NSIS 模板（`portable.nsi`）每次启动都会
`RMDir /r` 清空临时目录 → **把 320 MB 整个解压一遍** → 运行 → 退出时再删掉。
所以 10 秒里绝大部分是解压，跟机器快慢关系不大。想要"单文件又秒开"只能自己写启动器，
不如直接用上面两种。

### 改代码调试：双击 `启动.cmd`

源码方式运行，改完 `app.js` / `style.css` 刷新就能看效果。

> 第一次打开后**随便点一下页面**，系统才允许播放声音和语音。

### 自己重新打包

```
npm install              # 第一次
npm run build            # 安装版  → dist\iKunReminder-安装版.exe
npm run build:fast       # 绿色版  → dist\win-unpacked\
npm run build:portable   # 便携版  → dist\iKunReminder-便携版.exe
```

> 打包配置里写死了 `"signAndEditExecutable": false`。原因是 electron-builder 默认会下载一个
> 含 macOS 符号链接的 `winCodeSign` 工具包，普通（非管理员）Windows 账户解压时会报
> 「无法创建符号链接」而打包失败。关掉 exe 签名后就不下载它了，
> 而外壳的图标由 NSIS 负责，**坤坤图标照常显示**（实测导出来确认过）。
> 另外 `electronLanguages` 只保留了 `zh-CN` / `en-US`，能省掉几十种用不到的语言包。
>
> 「桌面快捷方式」那个勾选框是自己写的，在 `build/installer.nsh` 里，
> 通过 electron-builder 的三个钩子接进去：
> `customInit`（默认值）、`customPageAfterChangeDir`（插在选目录页之后的页面）、
> `customInstall`（electron-builder 建完快捷方式后，按勾选状态决定删不删）。
> 两个坑记一下：① 这个文件是在 MUI2 **之前**被 include 的，用到 `MUI_HEADER_TEXT` 的函数
> 必须写在 `customPageAfterChangeDir` 宏里；② 打卸载程序时也会 include 本文件，
> 整段要用 `!ifndef BUILD_UNINSTALLER` 挡掉，否则变量未使用会触发 warning 6001（被当作错误）。
> 文件必须存成**带 BOM 的 UTF-8**，否则 NSIS 会把中文按 ANSI 解析成乱码。
>
> **快捷方式图标**：快捷方式的图标取自目标 exe，而被安装的 `iKunReminder.exe` 自己**没有图标资源**
> —— 那要靠 rcedit 写进去，但 rcedit 是由 app-builder 的 Go 二进制执行的、需要解压 `winCodeSign`，
> 那个包里带 macOS 符号链接，普通 Windows 账户解压会报「无法创建符号链接」直接失败
> （`signAndEditExecutable: false` 就是为了绕开它）。
> 所以改成：`build/make-ico.js` 把 `icon.png` 转成 `build/icon.ico`
> （手写的 ICO 头 + PNG 内嵌，Vista+ 支持），用 `extraResources` 一起装到 `<安装目录>\resources\icon.ico`，
> 再在 `customInstall` 里让快捷方式直接指向它。实测桌面和开始菜单图标都变成坤坤头像了。

## 二、托盘

启动后右下角会出现一个**坤坤头像托盘图标**（和任务栏图标是同一张图），右键它：

| 菜单项 | 作用 |
| --- | --- |
| 显示坤坤 | 把窗口叫出来 |
| 宠物模式（只剩动画） | 打勾即缩成只剩动画的透明小窗，悬浮在右下角 |
| 💧 立即提醒喝水 / 🛋️ 立即提醒休息 | 立刻弹提醒（用来测试） |
| ⏸ 暂停计时 / ▶ 继续计时 | 临时免打扰 |
| 退出 | 真正退出程序 |

- **左键单击托盘图标** = 显示 / 收起窗口。
- **点窗口右上角 ✕** = 收进托盘（第一次会弹气泡提示），程序继续在后台计时。
- 到点提醒时窗口会自己从托盘弹出来、置顶、抢焦点；你点「我完成了 / 稍后再说」之后，
  它会**自己缩回托盘**，不打扰你干活。

## 三、宠物模式

点主界面上的「🐣 宠物模式」，或者右键托盘图标勾选，窗口就会变成一个 **150 × 170 的小窗**
并且**窗口背景完全透明**——**没有方框、没有边框、没有按钮、没有倒计时、没有标题栏**，
屏幕上只剩一只坤坤在那儿晃。**任务栏图标也会隐藏**，只在右下角托盘里留一个图标。

**宠物默认大小在主界面上就能设**：主界面左侧舞台下方有「🐣 宠物默认大小」三个档位
（迷你 150×170 / 小小 118×134 / 超小 92×104），选好之后会自动记住并立即生效。

在这个小窗里：

- **按住左键直接拖**：整个窗口都能拖（透明区域也能拖）。
  **窗口会被限制在屏幕可用区域内**，怎么拖都不会跑出屏幕外面去。
- **右键** → 原生菜单：
  - **显示主界面**：恢复完整窗口（任务栏图标也跟着回来）
  - **收进托盘**：藏起来后台继续计时
  - **调整倒计时** → 子菜单：💧 喝水间隔（15/30/45/60/90 分钟）、🛋️ 休息间隔（20/40/60/90/120 分钟）
  - **宠物大小** → 迷你（150×170，默认，最大档）／小小（118×134）／超小（92×104）
  - **退出坤坤**

**到点提醒时会自动切回大主界面**（小窗塞不下提醒弹层），完整显示动画和按钮；
你点完「我完成了 / 稍后再说」之后，它会**自动变回小宠物**继续待在角落。

## 六、常见问题

**Q：关了窗口就没了？**
点 ✕ 是收进托盘，还在后台计时。要真正退出：右键托盘图标 → 退出。

**Q：便携版 exe 第一次打开要等很久？**
便携版**每次**都要等 10 秒左右 —— 它每次启动都会把 320 MB 解压到临时目录，这是
electron-builder 便携版的固有设计（见上面「便携版为什么慢」）。
想要快就换成安装版或绿色解压版，**1 秒以内**。

**Q：便携版会被杀毒软件/SmartScreen 拦？**
可能性有。便携 exe 是从压缩包解出来的，Windows 可能给它打上「来自 Internet」标记。
解决：**先右键 exe → 属性 → 勾选「解除锁定」**，再运行；杀毒软件误报就加个白名单
（Electron 打包的绿色软件比较容易被启发式引擎盯上）。

**Q：宠物模式里怎么没有按钮？**
故意的，只剩坤坤。所有操作都在**右键菜单**里；**按住左键直接拖**就能把坤坤挪到任意位置
（拖不出屏幕范围）；嫌大嫌小可以在右键菜单 →「宠物大小」，或者回主界面用「宠物默认大小」选。

**Q：宠物模式下来提醒了会怎样？**
会自动切回**大主界面**显示完整提醒（小窗塞不下），你点完「我完成了 / 稍后再说」后
它又自动变回小宠物待在角落。

**Q：没声音 / 没语音？**
先和页面交互一次（点一下「🎤 试听提醒」解锁音频）。语音用系统自带的 `speechSynthesis` 中文语音。

**Q：托盘里找不到图标？**
Windows 会把不常用的图标折叠进「隐藏的图标」小三角里，拖出来固定即可。

**Q：想开机自启？**
把 `启动.cmd` 的快捷方式丢进 `Win + R` → `shell:startup` 打开的启动文件夹。

**Q：想改默认间隔 / 角色大小？**
`app.js` 顶部 `settings` 改 `minutes`；角色大小改 `setPetMode()` 和 `new Kunkun(...)` 里的 `fit`（数值越小角色越大）。

## 七、给程序员的备注

- **抢前台**：渲染进程到点调 `window.kunkunNative.alert()` → 主进程
  `restore → show → setAlwaysOnTop('screen-saver') → moveTop → focus → flashFrame`；
  `dismiss()` 后取消置顶，若提醒前藏在托盘里还会自动缩回去。
- **托盘 + 无边框 + 透明**：窗口 `frame:false` + `transparent:true`，普通模式靠页面自身的不透明背景
  铺满窗口，宠物模式把背景全部设为透明，于是屏幕上只剩坤坤本体。
  `close` 事件里 `preventDefault()` 改为 `hide()`，只有 `before-quit` 才真退出。
- **拖窗**：没用 `-webkit-app-region: drag` ——它在透明窗口上不生效（宠物窗拖不动就是这个原因），
  改成页面里监听 `pointerdown/move/up`，把 `screenX/screenY` 的位移发给主进程 `win.setBounds()`
  自己算偏移，透明区域和普通标题栏都能拖，且不影响右键。
  位置用 `screen.getDisplayNearestPoint()` 取鼠标所在显示器的 `workArea` 做钳制，
  窗口永远不会被拖出屏幕（多显示器、负坐标也都对）。
- **等比缩放**：页面里有个固定 1180px 宽的设计容器 `#app`，窗口尺寸变化时按
  `min(可用宽/1180, 可用高/内容高)` 算比例，用 `transform: scale()` 缩放并居中；
  内容高是运行时量的，避免最后一截被切掉。画布的 `resize()` 改用 `offsetWidth/offsetHeight`
  （不受 transform 影响）拿布局尺寸，再乘上 `devicePixelRatio × 缩放比` 分配像素，缩放后不会发虚。
- **提醒与宠物模式**：`bringToFront()` 里如果当前是宠物模式，先 `applyPetMode(false)` 切回大主界面
  （否则 150×170 的小窗塞不下弹层），并在 `dismiss` 后延迟 1.8 秒自动变回宠物。
  窗口的 `minWidth/minHeight` 要按模式切换（主界面 760×560，宠物模式 80×80），
  否则宠物窗缩不到最小档。
- **任务栏图标**：宠物模式 `setSkipTaskbar(true)`，回主界面 `setSkipTaskbar(false)`。
  注意：Electron 在 Windows 上**不是**靠 `WS_EX_TOOLWINDOW` 实现的，所以用
  `GetWindowLongPtr(GWL_EXSTYLE)` 去验证会得到"没生效"的误判——
  实际要截任务栏截图肉眼比对才准（实测按钮确实会消失）。
- **图标同一张图**：`icon.png`(256) 和 `tray.png`(32) 由同一张画布渲染后再缩放，
  保证任务栏和托盘看到的完全是同一个坤坤头像。
- **计时**：用 `Date.now()` 时间差推进而非累加，被节流或系统休眠后回到前台按真实时间结算；
  Electron 侧另开 `backgroundThrottling: false`。
- **动画**：`requestAnimationFrame` + Canvas 2D 实时绘制，用了挤压拉伸（腾空拉长 / 落地压扁）、
  呼吸、头发延迟半拍的跟随甩动；篮球被持球手用两段式 IK 真实跟随（运球 / 抱起 / 欢呼三种状态）。
- **音效**：Web Audio `OscillatorNode` 实时合成，没有音频文件。
- **安全**：`contextIsolation: true` + `nodeIntegration: false` + 严格 CSP。
