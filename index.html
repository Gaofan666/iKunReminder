⏰ 待办事项

设好日期和时间，到点会自动跳出来提醒你（过期未完成的，下次打开程序时补提醒一次）。

⚙ 设置

勾上之后，开机时程序会直接藏在右下角托盘里，不会弹出主界面； 到点照样会跳出来提醒。用的是当前用户的注册表启动项（不需要管理员权限）， 也能在「任务管理器 → 启动」里自己关掉。

关掉的话，待办到点只弹窗提醒、不抢前台（不打断你正在做的事）。

比如约了下午 3 点，但当时程序没开；下次打开时会弹出来告诉你这条已经过期。

提醒事项、备忘、待办这些都存在程序自己的本地存储里；点这里可以看到程序所在目录。

⬆ 软件更新

🐟 一键摸鱼

开着的时候，按下面的快捷键就会：先把桌面上所有窗口收起来， 再自动打开你指定的程序或文档 —— 文档会自动最大化，程序打开就行。 再按一次快捷键，刚才收起来的窗口全部还原（伪装软件留着不动）。 桌面上的小鸡不受影响。

伪装目标

还没选。不选也行 —— 那就只把桌面收干净，不打开任何东西。

快捷键

默认是 Ctrl + Alt + M。 要包含 Ctrl 或 Alt，也可以直接用 F1～F12 这种功能键 —— 免得跟打字冲突。
