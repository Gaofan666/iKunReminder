⚙ 设置

勾上之后，开机时程序会直接藏在右下角托盘里，不会弹出主界面； 到点照样会跳出来提醒。不需要管理员权限，也能在「任务管理器 → 启动」里自己关掉。

关掉的话，待办到点只弹窗提醒、不抢前台（不打断你正在做的事）。

比如约了下午 3 点，但当时程序没开；下次打开时会弹出来告诉你这条已经过期。

🎵 提醒音乐

当前：自带音乐

想换成自己喜欢的一段，点「选择音乐文件」挑一个就行 —— 支持 mp3 / wav / ogg / m4a / flac 等常见格式，建议不超过 10 MB（文件越大加载越慢）。 文件被删掉或挪走后会自动退回自带音乐。提醒时要不要放音乐，由主界面上「提醒音乐」那个开关控制。

提醒事项、备忘、待办这些都存在程序自己的本地存储里；点这里可以看到程序所在目录。 自定义宠物皮肤放在skins 文件夹里， 软件更新不会把它删掉（更新前会自动备份、装完放回来），文件夹里有详细说明。

🐟 一键摸鱼

开着的时候，按下面的快捷键就会：先把桌面上所有窗口收起来， 再自动打开你指定的程序或文档 —— 文档会自动最大化，程序打开就行。 再按一次快捷键，刚才收起来的窗口全部还原（伪装软件留着不动）。 桌面上的小鸡不受影响，壁纸类软件也不会被碰。

伪装目标

还没选。不选也行 —— 那就只把桌面收干净，不打开任何东西。

快捷键

默认是 Ctrl + Alt + M。 要包含 Ctrl 或 Alt，也可以直接用 F1～F12 这种功能键 —— 免得跟打字冲突。

—

连击用哪个键

只开放修饰键和功能键：字母数字键要是也能选， 打字时连按三下同一个字母就会当场把桌面收走。 选「Ctrl（左右都算）」的话，左 Ctrl 和右 Ctrl 都算数。

🌙 护眼模式

把屏幕调暖、少放蓝光，看久了眼睛不容易累（是真的把颜色调暖， 不是叠一层黄颜色）。主界面「桌面宠物」那一行也有同一个开关，勾哪边都一样。 开了 HDR、或者显示器不支持的时候，勾了也不会生效（这儿会说明原因）。

色温

4500K

默认 4500K，和 Windows 夜间模式的中间档差不多。 数值越小越暖、蓝光越少；6500K 基本就是屏幕原色（等于没开）。 拖动时会立刻生效，松手就记住；这里拖了会自动把护眼模式打开。 有些显示器不支持太暖的值，拖过头时会自动退到能接受的最暖温度， 滑杆也会跟着吸回去。关掉护眼模式会还原成你原来的色温，不会留下痕迹。

勾着（默认）：关掉程序就把色温恢复成你原来的样子，不留痕迹。 取消勾选：退出后屏幕继续保持护眼色温 —— 想让它一直暖着就取消它。 注意取消之后，退出程序就没法再把色温调回来了； 要还原得重新打开程序，把上面的「启用护眼模式」取消勾选。
